# Jekyll Introducción

Se ha creado un segundo sitio web estático utilizando Jekyll.

Jekyll permite generar sites estáticos a partir de archivos Markdown, **HTML** y otros.

## Instalación

En este apartado se documentará la instalación de las dependencias necesarias para utilizar Jekyll.

## Creación del sitio

Se creará una web personal sencilla utilizando Jekyll y se generará el contenido estático del sitio.

Configuración de **NGINX**

Una vez generado el sitio, se configurará un segundo servidor virtual de **NGINX** para servir los archivos generados por Jekyll.

## Comprobación

Finalmente, se comprobará desde el navegador que el segundo sitio web funciona correctamente.
