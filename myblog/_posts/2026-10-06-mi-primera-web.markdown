He empezado a experimentar con Jekyll, una herramienta que permite crear sitios web estáticos.

La verdad es que al principio resulta un poco extraño trabajar con nuevas herramientas pero luego te das cuenta de que no es tan difícil crear algo sencillo.

Para este proyecto he creado mi primer blog con Jekyll y he aprendido a generar el sitio estático usando NGINX como servidor web.

Puedo escribir las entradas en Markdown y dejar que Jekyll se encargue de generar las páginas.

Este blog también podría servirme como un lugar para publicar lo que vaya aprendiendo durante el ciclo de DAW.
